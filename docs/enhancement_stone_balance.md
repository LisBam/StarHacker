# 强化石属性收益平衡设计

本文档记录强化石单词条幅度的设计目标、收益模型、换算公式、当前系数和调整流程，用于后续数值平衡与回归校验。玩家实际获得的区间与玩法规则以 `游戏机制与玩法内容.md` 为准，运行时配置以 `res://scripts/data/enhancement_rules.gd` 为准；三者发生变更时必须同步维护。

## 1. 平衡目标

强化石平衡通常以“同品质、同方向、单条有效词条的期望战斗收益相等”为基准，不比较一颗强化石最终包含多少条词条。该连续收益模型适用于初级、中级、高级和极品四个普通品质；特化品质的弹射、连击、穿透和散射是离散机制例外，不使用伤害锚点换算。攻击距离、移速与视野是普通品质当前明确的数值例外：攻击距离的增强和削弱区间均缩小到原触达区间的五分之一，移速与视野均缩小到各自原平衡区间的四分之一，三者统一按 `0.1%` 精度取最近合法端点：

- 除攻击距离、移速与视野外，同品质任意 1 条增强词条具有相同的目标正收益。
- 除攻击距离、移速与视野外，同品质任意 1 条削弱词条具有相同的目标负收益。
- 除攻击距离、移速与视野外，同品质、同词条数量与同正负构成的强化石具有相同的目标净收益；包含这三项特例时按其独立区间计算。
- 属性刷新权重只控制词条出现频率，不直接参与幅度公式。攻击距离的五分之一幅度、移速与视野的四分之一幅度是独立玩法规则，能量恢复仍遵循标准收益换算。
- 不要求增强收益与削弱损失互相相等。每个品质分别维护增强锚点和削弱锚点，高品质可以同时拥有更高正收益和更低负风险。

设某品质每条增强词条的期望效用为 `mu_plus`，每条削弱词条的期望损失为 `mu_minus`，则一颗包含 `n_plus` 条增强与 `n_minus` 条削弱的强化石目标净效用为：

```text
E[U_stone] = n_plus * mu_plus - n_minus * mu_minus
```

因此，标准属性的两条增强组合目标期望是 `2 * mu_plus`，两条增强加一条削弱的目标期望是 `2 * mu_plus - mu_minus`。包含攻击距离、移速或视野时，应改用对应属性当前独立区间的实际效用。词条数量概率、品质掉落概率与升阶规则属于产出平衡，不进入本文件的单词条幅度换算。

## 2. 适用范围与限制

- 当前连续收益模型覆盖武器和装备强化石的全部普通品质词条，以及特化武器石负面属性的初级削弱幅度。
- 散射、穿透、弹射和连击只进入特化武器强化石的正向属性池，固定 `+1`、极低概率 `+2`，不参与本文的连续收益换算。
- 强化石只对目标实际拥有且兼容的属性生效；未生效词条不掷幅度，也不计入本次实际收益。
- 模型比较的是指定基准状态下的边际收益，不保证每种武器、装备、敌人和战斗距离下的瞬时结果完全一致。
- 伤害、冷却、暴击、闪避等属性可以通过公式换算；偏移、坐力、冲击、距离、视野等间接属性必须依赖设计系数和实战数据标定。
- 暴击率 100%、闪避率 80%、冷却缩减 40%、能量恢复最低 0 等边界会截断实际收益。接近边界的角色不属于标准换算状态，不能据此反向放大全局区间。
- 能耗的最终有效值会取整为整数，低基础能耗可能使一次百分比变化不足以跨过整数边界。能耗回归必须覆盖当前武器的实际基础能耗分布，不能只验证连续公式。
- 冷却缩减的最终有效值最低为 0%。基础冷却缩减为 0% 的腿部装备受到削弱词条时，当次即时负收益会被下限截断；现有削弱区间只在目标拥有足够冷却缩减时符合边际收益模型。

## 3. 数值表示与随机期望

### 3.1 三类结算公式

| 类型 | 结算公式 | 当前属性 |
| --- | --- | --- |
| 乘算比例 | `最终值 = 基础值 * (1 + 增强比例 - 削弱比例)` | 伤害、冷却、能耗、弹体速度、攻击距离、偏移、后坐力、前坐力、冲击力、判定时长、耐久、攻击力、防御力、最大生命、每 5 秒回血 |
| 加算百分点 | `最终值 = 基础值 + 增强百分点 - 削弱百分点` | 暴击率、暴击伤害、闪避率、冷却缩减、移速、视野 |
| 加算数值 | `最终值 = 基础值 + 增强点数 - 削弱点数` | 能量恢复；特化弹射、连击、穿透、散射 |

乘算比例与加算百分点都以 `0.001` 为抽取步长，即 `0.1%` 或 `0.1` 个百分点；能量恢复以 `0.1` 点/秒为抽取步长。攻击距离在原触达区间缩小到五分之一后继续使用乘算步长，例如 `9.6% ÷ 5 = 1.92%` 取为 `1.9%`、`2.4% ÷ 5 = 0.48%` 取为 `0.5%`。移速与视野使用加算百分点，并在原平衡区间缩小到四分之一后继续使用相同步长；精确四等分得到 `0.75%`、`0.45%` 或 `3.75%` 的端点分别取为最近合法值 `0.8%`、`0.5%` 或 `3.8%`。区间包含最小值和最大值，运行时在全部合法离散值中等概率抽取。

线性属性的区间期望可直接使用 `(min + max) / 2`。冷却、闪避等非线性属性应使用离散均值回代：

```text
E[U] = (U(x_1) + U(x_2) + ... + U(x_N)) / N
```

后续调整时不能只比较显示区间的中点；完成步长取整后还需要比较每个可抽值的实际效用均值。

### 3.2 品质收益锚点

伤害词条是普通四品质单词条的目标收益锚点。下表中的百分比表示相对战斗收益或损失，增强与削弱分别换算；特化正向离散机制不添加第五行收益锚点，特化负面属性直接复用初级削弱行：

| 品质 | 增强目标区间 | 增强目标期望 | 削弱目标区间 | 削弱目标期望 |
| --- | ---: | ---: | ---: | ---: |
| 初级 | 0.5%–1.2% | 0.85% | 0.5%–1.2% | 0.85% |
| 中级 | 1.0%–2.0% | 1.50% | 0.3%–1.0% | 0.65% |
| 高级 | 1.8%–3.0% | 2.40% | 0.3%–0.8% | 0.55% |
| 极品 | 2.5%–4.0% | 3.25% | 无 | 无 |

设锚点端点为小数 `r`，例如 `0.5%` 写作 `0.005`。每个属性分别求出能够产生 `r` 正收益或 `r` 负收益的实际幅度，再按该属性步长取整。不得先把所有属性套用相同百分比，再用词条稀有度补偿。

## 4. 战斗公式基准

### 4.1 统一伤害公式

忽略最终整数取整与最低 1 点保护时，单次伤害为：

```text
Damage = RawDamage * (AttackPower + 100) / (DefensePower + 100)
       * CriticalModifier * IncreasedDamageZone * ReducedDamageZone
```

期望暴击系数为：

```text
K_crit = 1 + CriticalChance * (CriticalDamage - 1)
```

伤害强化石直接改变 `RawDamage`，因此伤害增加 `r` 时，在其他量不变的条件下伤害收益就是 `r`。攻击力改变的是攻防分式的分子，不能与伤害词条使用同一幅度。

### 4.2 攻击力换算

设当前总攻击力为 `A`，被强化装备的基础攻击力为 `B`，装备攻击力提高比例为 `x`，则忽略其他倍率变化时：

```text
DeltaA = B * x
RelativeDamageGain = DeltaA / (A + 100)
x = r * (A + 100) / B
```

当前表使用约 `14` 倍伤害锚点的攻击力幅度。该系数对应完整装备后的代表状态，例如总攻击力约 `180`、单件装备攻击力约 `20` 时，`(180 + 100) / 20 = 14`。这就是攻击力强化区间明显高于伤害强化区间的原因。

### 4.3 防御力换算

承受伤害与 `1 / (DefensePower + 100)` 成正比，因此在攻击方不变时，有效承伤能力与 `DefensePower + 100` 成正比。设当前总防御力为 `D`，被强化装备的基础防御力为 `B_def`：

```text
DeltaD = B_def * x
RelativeSurvivalGain = DeltaD / (D + 100)
x = r * (D + 100) / B_def
```

当前表使用约 `12` 倍伤害锚点的防御力幅度，用于近似现有角色穿戴整套装备后的平均稀释比例。攻击力与防御力系数必须在角色基础属性、装备基础值或攻防平滑常数发生变化时重新采样。

## 5. 可精确换算的属性

### 5.1 武器冷却

攻击频率与冷却时长互为倒数。设冷却减少或增加比例为 `x`：

```text
增强收益 = 1 / (1 - x) - 1
削弱损失 = 1 - 1 / (1 + x)
```

令结果等于锚点 `r`，可得：

```text
增强：x = r / (1 + r)
削弱：x = r / (1 - r)
```

因此冷却区间与伤害区间接近，但高端点会因倒数关系略低或略高，不能永远直接复制伤害区间。

### 5.2 暴击率

暴击率使用 `20%` 暴击率、`200%` 暴击伤害作为独立基准：

```text
c = 0.20
m = 2.00
K_crit = 1 + 0.20 * (2.00 - 1) = 1.20
DeltaCriticalChance = r * K_crit / (m - 1) = 1.20r
```

例如伤害收益锚点为 `0.5%` 时，等价暴击率增量为 `0.6` 个百分点。暴击率区间不得使用暴击伤害的基准状态推导。

### 5.3 暴击伤害

暴击伤害使用 `80%` 暴击率、`150%` 暴击伤害作为独立基准：

```text
c = 0.80
m = 1.50
K_crit = 1 + 0.80 * (1.50 - 1) = 1.40
DeltaCriticalDamage = r * K_crit / c = 1.75r
```

例如伤害收益锚点为 `0.5%` 时，等价暴击伤害增量为 `0.875` 个百分点，按 `0.1` 个百分点步长取为 `0.9`。两个暴击词条数值大小不同，是因为使用的基准暴击状态和边际收益不同，而不是因为其中一个词条被额外降权。

### 5.4 闪避率

当前闪避模型使用 `10%` 基准闪避率 `e = 0.10`，并以有效承伤能力衡量收益。增加 `x` 闪避与减少 `x` 闪避的换算分别为：

```text
增强收益 = (1 - e) / (1 - e - x) - 1
削弱损失 = 1 - (1 - e) / (1 - e + x)

增强：x = r * (1 - e) / (1 + r)
削弱：x = r * (1 - e) / (1 - r)
```

闪避率接近 80% 上限时边际收益会显著偏离基准，验收时应同时检查标准状态与封顶状态，但不能用封顶状态替换全局基准。

### 5.5 主动技能冷却缩减

增强换算的当前基准冷却缩减为 `0%`。若主动技能冷却按 `BaseCooldown * (1 - CooldownReduction)` 结算，则在该基准下与武器冷却使用相同的倒数换算。对已经拥有冷却缩减 `q` 且削弱后仍不低于 0% 的装备，统一公式为：

```text
增强：x = r * (1 - q) / (1 + r)
削弱：x = r * (1 - q) / (1 - r)
```

削弱测试的 `q` 必须不小于削弱区间最大端点，否则实际冷却缩减会被限制到 0%，超出下限的部分不再产生负收益。最终冷却缩减同时受 40% 上限限制，超过上限的增强部分不再缩短主动技能冷却。开拓之裤和半截垃圾桶的基础冷却缩减为 0%，因此当前削弱词条对它们没有即时战斗损失，只会先抵消以后获得的冷却缩减增强；端口网裤的基础冷却缩减为 5%，能够用于完整的削弱区间回代。

## 6. 间接收益系数

下表中的系数是当前设计模型，不是引擎自动产生的数学常量。`x = coefficient * r` 表示先用伤害锚点端点求出候选幅度，再按抽取步长取整并进行实战回代。

| 属性或属性组 | 当前换算 | 设计依据 |
| --- | ---: | --- |
| 伤害 | `x = 1r` | 直接线性改变原始伤害 |
| 能耗 | 约 `x = 4r`，增强与削弱分别非线性回代 | 假设约 25% 战斗时间受到能量约束 |
| 偏移、后坐力、前坐力、冲击力 | `x = 4r` | 命中稳定与站位安全的间接收益 |
| 移速 | 约 `x = 1r` | 原 `4r` 区间缩小至四分之一，并按 `0.1%` 精度适配 |
| 弹体速度、判定时长、耐久、最大生命 | `x = 8r` | 触达、容错、单件装备占总属性比例与非持续生效稀释 |
| 攻击距离 | 约 `x = 1.6r` | 原 `8r` 触达区间缩小至五分之一，并按 `0.1%` 精度适配 |
| 每 5 秒回血 | `x = 6r` | 持续生存收益不直接等于单次输出 |
| 视野 | 约 `x = 1.5r` | 原 `6r` 区间缩小至四分之一，并按 `0.1%` 精度适配 |
| 攻击力 | `x = 14r` | 总攻击力与单件装备攻击力在攻防公式中的稀释 |
| 防御力 | `x = 12r` | 总防御力与单件装备防御力在有效承伤能力中的稀释 |
| 能量恢复 | 约 `x = 80r` 点/秒 | 代表总恢复约 20 点/秒、约 25% 时间受能量约束 |

能耗和能量恢复的 25% 是标准战斗占空比假设。若遥测显示玩家几乎从不缺能量，两者实际收益会低于目标；若玩家长期处于能量耗尽状态，两者实际收益会高于目标。调整时应先改变占空比假设或代表恢复值，再统一重算四个品质，不能逐个端点凭感觉修补。

## 7. 当前幅度快照

属性资格补充：头部固定提供“视野”、躯体固定提供“能量恢复”、腿部固定提供“冷却缩减”、脚部固定提供“移速”。即使模板基础值为 0，部位仍显示该属性并允许强化；冷却缩减、移速和视野按百分点直接加算，能量恢复按点数直接加算。强化石筛选界面按“增强 / 削弱”分组，锻造来源额外提供全部、初级、中级、高级、极品、特化品质筛选，下拉列表只显示品质名称，不添加“品质：”前缀。暴击率属于加算百分点，武器基础暴击率为 0 时也必须允许强化并将增量直接加到最终暴击率。

暴击率悬停详情固定保留 `0.1%` 显示精度，与强化石 `0.1` 个百分点的抽取和累计步长一致。

耐久上限强化会保持强化前当前耐久比例，再换算到新的耐久上限；因此提高或降低耐久上限不会额外改变既有损耗进度。

### 7.4 强化后物品价值换算

武器与装备的强化价值统一读取“当前真正生效的属性变化”，不再直接把强化词典中的原始数值相加。每个词条先经过属性上限、下限和整数取整，再换算为相对基础价值的等效收益比例；因此修改本文件对应的强化石幅度后，物品价值会自动跟随新幅度变化，不需要维护第二份静态价格表。

| 属性或属性组 | 价值换算 |
| --- | --- |
| 伤害 | 实际相对变化直接计入 |
| 冷却、冷却缩减 | 按攻击频率倒数公式换算增强或损失 |
| 暴击率、暴击伤害、闪避率 | 使用本文第 5 节相同参考状态与非线性公式 |
| 能耗、偏移、后坐力、前坐力、冲击力 | 实际相对变化除以 4 |
| 弹体速度、攻击距离、判定时长、耐久、最大生命 | 实际相对变化除以 8 |
| 每 5 秒回血 | 实际相对变化除以 6 |
| 攻击力 | 实际相对变化除以 14 |
| 防御力 | 实际相对变化除以 12 |
| 能量恢复 | 实际点数变化除以 80 |
| 移速 | 实际加算百分点直接计入 |
| 视野 | 实际加算百分点除以 1.5 |
| 特化弹射、连击、穿透、散射 | 每点计入 20% 基础价值 |

增强换算结果为正、削弱换算结果为负；被 0 下限、属性上限或整数取整完全截断的变化不影响价值。满耐久强化价值倍率最低为基础价值的 10%，之后再乘当前耐久价值倍率。

## 8. 后续调整流程

1. 固定本轮代表状态，包括武器、四件装备、角色攻防、目标防御、暴击状态、闪避状态、战斗距离和能量约束占空比。
2. 决定是否调整伤害锚点。只调整某个属性时保持普通四品质锚点不变，避免同时移动目标与换算结果；特化离散机制另行使用场景测试。
3. 为属性定义可测量的效用函数。输出属性使用期望伤害或持续输出，生存属性使用有效承伤能力，操控属性使用命中率、受击率、有效攻击时间或完成固定遭遇的时间。
4. 分别求解增强和削弱的每个区间端点，不使用增强区间的相反数代替削弱换算。
5. 按 `0.1%`、`0.1` 个百分点或 `0.1` 点/秒取整，再枚举闭区间内全部可抽值，检查离散期望。
6. 对一条增强、一条削弱、两条增强、两条增强加一条削弱分别回归，确认相同品质和相同正负构成的组合只由词条数量决定目标收益。
7. 检查 0 值、不兼容属性、暴击与闪避上限、冷却缩减与能量恢复下限、冷却与判定时长下限，并使用实际武器基础能耗检查整数取整，确认边界只截断实际效果而不会生成非法值。
8. 将最终区间写入 `EnhancementRules` 对应属性表，并同步本文件和 `游戏机制与玩法内容.md` 的数值快照。

## 9. 参数变化时的重算触发条件

出现以下任一变化时，必须重新审视相关换算，而不是沿用旧区间：

- 伤害公式中的攻防平滑常数不再是 `100`。
- 角色基础攻击力、防御力或装备单件平均属性发生系统性变化。
- 暴击率基准不再是 `20% / 200%`，或暴击伤害基准不再是 `80% / 150%`。
- 闪避标准状态不再是 10%，或闪避上限不再是 80%。
- 主动技能冷却缩减上限不再是 40%。
- 主动技能冷却缩减成为普遍基础属性，不再以 0% 为代表状态。
- 能量受限战斗时间显著偏离 25%，或代表能量恢复显著偏离 20 点/秒。
- 新增命中率、有效射程、击退收益、视野收益或耐久消耗的遥测数据，足以替换当前经验系数。
- 新增强化石属性、改变属性公式类型、改变随机步长或重新允许离散机制进入强化石池。

## 10. 验收标准

- 除攻击距离、移速与视野外，普通同品质所有增强属性的离散期望效用落在统一目标容差内；攻击距离按原触达区间五分之一目标验收，移速与视野按各自四分之一目标验收，特化正向机制按 7.3 的离散规则验收。
- 除攻击距离、移速与视野外，普通同品质所有削弱属性的离散期望损失落在统一目标容差内；攻击距离按原触达区间五分之一目标验收，移速与视野按各自四分之一目标验收，特化负面属性按初级削弱目标验收。
- 公式属性默认使用 `5%` 相对误差容差；间接属性在缺少稳定遥测前使用 `15%` 容差，并记录样本场景。
- 普通每种品质至少验证区间最小值、最大值和离散期望，特化品质额外验证属性池、生成概率与 +1/+2 点数；不以单次随机结果代替统计结论。
- 能耗必须按每种基础能耗分别统计跨越整数边界后的实际收益；冷却缩减削弱必须同时报告未触及 0% 下限与触及下限的结果。
- 数值平衡验收不混入词条数量概率、掉落品质概率、稀有属性权重或市场价格。
- 当前实现、玩家机制快照与本设计文档中的公式、基准和区间保持一致。
- 特化正向词条只使用 +1/+2，`+2` 统计概率符合 0.01%；特化负面词条统计概率符合 80%，且每一项的最小值、最大值和离散期望与初级削弱完全一致。
