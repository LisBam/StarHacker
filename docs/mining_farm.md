# 量子算力矿场

本文档记录量子算力矿场的长期架构、公开接口、存档边界与 UI 维护约定。玩法规则和全部当前数值的权威快照同时维护在 `docs/游戏机制与玩法内容.md`。

## 模块职责

- `res://scripts/game/mining_farm_service.gd` 通过 `project.godot` 自动加载为 `MiningFarmService`。服务跨全部场景常驻，独立维护整数算力币、永久资产数量、永久解锁状态、在线增益、产出结算和 `user://mining_farm_state.json`。
- `res://scripts/ui/mining_farm_panel.gd` 只负责界面、整数输入、卡片列表和数值动画，不持有真实余额或资产所有权。关闭面板后停止 `_process()`、进度条和卡片动效，服务继续后台低频结算。
- `res://scripts/ui/main_menu.gd` 只负责创建矿场遮罩和打开/关闭面板。主菜单场景中的 `MiningFarmButton` 位于炒股入口右侧。
- `res://scripts/ui/combat_hud.gd` 在正式骇入成功撤离时，把结算前的随身物品总价值上报给矿场服务；死亡、主动逃跑和训练场不会调用该接口。
- `res://scripts/game/stock_market_service.gd` 在每次行情刷新完成后发送 `market_refreshed(refresh_source)`。矿场只处理 `settlement` 正式全量刷新，并读取稳定股票标识 `hacker_tech` 的 `last_change_ratio`。

## 在线结算

- 服务使用 `PROCESS_MODE_ALWAYS`，主菜单、局外面板、战斗和暂停界面都属于在线时间；程序关闭后没有帧回调，因此不计算离线收益，也不保存退出时间戳。
- 面板打开时默认每 1 秒结算，面板关闭时默认每 5 秒批量结算。服务只取累计时间中的完整整数秒，余下小数继续保留，因此切换场景和帧率变化不会丢失时间。
- 单次收益为 `当前整数每秒产出 × 完整秒数`。基础资产产出均为整数；全部百分比增益先加算，再对总基础产出向下取整。
- `set_panel_open(true)` 会先结算后台累计的完整秒数，面板随后从上次关闭余额滚动到真实余额，并显示累计新增收益。

## 资产与解锁

- 所有资产定义集中在 `MiningFarmService.ASSET_DEFINITIONS`，包含稳定标识、名称、官方购买价、单台产出、基础总产出解锁门槛和世界观说明。
- 资产数量为非负整数且无上限。购买后立即加入持有数量，下一结算周期开始产出；出售后立即移除数量并降低总产出。
- 解锁只读取不含临时增益的基础总产出。达到门槛后写入永久解锁表，之后即使出售全部资产也不会重新锁定。
- 出售返还始终读取当前官方购买价，按 60% 计算并向上取整，不保存或读取历史买入成本。

## 货币交换

- `recharge(gold_amount)` 只接受正整数金币，先调用 `GlobalInventory.spend_coins()` 原子扣款，再按 1:10000 增加算力币。
- `withdraw(gold_amount)` 的参数表示希望到账的整数金币。所需算力币为 `ceil(金币 × 10000 ÷ 0.9)`，余额充足后扣除算力币并调用 `GlobalInventory.adjust_coins()`。
- 成功充值和提现会立即保存矿场与完整库存存档，缩短两个独立资产文件之间的不一致窗口；普通产出和资产交易使用默认 0.5 秒合并写入。

## 临时增益

- 成功撤离调用 `apply_successful_extraction_buff(extracted_value_gold)`。每 10 金币价值增加 0.01% 产出，单次追加 1800 秒在线持续时间；多次成功撤离的比例和剩余在线时长直接叠加。
- 骇客数字科技在一次 `settlement` 全量刷新中上涨至少 10% 时，股市联动提高 15% 产出。下一次 `settlement` 刷新先结束旧状态，再按新一轮涨幅决定是否立即重新激活。
- 两类增益与彼此加算，最终公式为 `floor(基础总产出 × (1 + 骇入增益比例 + 股市联动比例))`。

## UI 维护约定

- 顶部显示动画余额、四位小数金币折合值、绿色每秒产出和增益倒计时；底部 1 秒进度条只表达产出节律，不参与结算。
- 可购买资产页保持成长阶梯顺序；已持有资产页按单台产出从高到低排序，并隐藏数量为 0 的资产。
- 资产购买、出售、充值和提现统一复用股市使用的 `SellQuantityDialog`，通过滑条与数字输入选择整数数量；数量确认后继续复用 `CommonConfirmationDialog` 展示第二次确认，最终确认时服务再次校验余额、解锁与持有量。
- 余额右侧“显示具体数值”开关默认关闭；关闭时大数使用 K、M、B 两位小数缩写，开启后当前余额、每秒产出、卡片价格、产出、数量、解锁门槛和交易确认金额全部显示真实整数。
- 每张资产卡片在名称右侧显示绿色收益飘字：可购买页显示单台每秒收益，已持有页显示该类资产总每秒收益。
- 大于等于 10000 的显示值使用 K、M、B 并保留两位小数；该换算仅用于文本，真实余额、价格、产出和资产数量始终为整数。

## 存档结构

`user://mining_farm_state.json` 当前版本为 1，保存以下字段：

- `balance`：非负整数算力币余额。
- `asset_quantities`：稳定资产标识到非负整数持有数量的映射。
- `unlocked_assets`：稳定资产标识到永久解锁布尔值的映射。
- `hack_buff_ratio`：当前叠加的骇入产出比例。
- `hack_buff_remaining_seconds`：只按在线帧递减的剩余秒数。
- `stock_buff_active`：当前股市联动是否生效。

存档不记录系统时间或退出时间，因此读取存档不会补发离线收益，也不会扣除离线期间的增益时长。
