# 星海银行

本文档说明星海银行系统的服务职责、利率口径、贷款级联扣款与持久化边界。玩家可见数值以《游戏机制与玩法内容》为准。

## 1. 系统定位

- 银行补全局外金融光谱的“保本与信用”一角：股市高波动、矿场纯挂机、银行低风险生息并提供唯一的借贷杠杆。
- 三个子玩法：活期账户（随存随取、按在线小时计息）、定期存单（锁仓换高息、签订时按大盘锁定利率）、信用贷款（按总资产授信、到期自动级联扣款）。

## 2. 服务与职责

| 部分 | 实现 | 职责 |
| --- | --- | --- |
| 银行服务 | `res://scripts/game/bank_service.gd`（AutoLoad `BankService`） | 维护活期余额、计息、存单、贷款、违约冻结与独立存档 |
| 银行面板 | `res://scripts/ui/bank_panel.gd` | 活期/定期/贷款三标签页；金额输入复用 `SellQuantityDialog.present_developer_value()` 通用整数模式 |
| 主菜单入口 | `main_menu.gd` 底部“银行”按钮与大厅 `bank` 动作 | 动态创建遮罩与面板 |

## 3. 核心数值

| 规则 | 数值 |
| --- | --- |
| 活期计息 | 每满 3600 在线秒按当时余额结算一次 `floor(余额 × 0.2%)`，存取无手续费 |
| 定期三档 | 短期 1800 秒基础 1.0% / 标准 7200 秒基础 4.5% / 长期 21600 秒基础 15.0% |
| 定期利率修正 | 签订瞬间锁定：`基础利率 × 大盘倍率 × 金库倍率`；牛市 ×0.9、熊市 ×1.25、震荡 ×1.0；星海金库每级 +4% |
| 定期本息 | `本金 + floor(本金 × 锁定利率)`，到期自动发放到局外星穹并广播 `deposit_matured` |
| 贷款授信 | `floor(总资产 × 50%)`；总资产 = 局外星穹 + 活期余额 + 定期本金 + `floor(证券币)` + `算力币 ÷ 10000` 取整 |
| 贷款利息 | 应还 = `ceil(本金 × 1.15)`，期限 7200 在线秒，同一时间一笔 |
| 违约冻结 | 21600 在线秒内不能申请新贷款与签订新存单 |

## 4. 贷款级联扣款

到期未主动还清时按固定顺序自动抵扣，剩余债务逐层递减：

1. 局外星穹（`GlobalInventory.spend_coins`）。
2. 银行活期余额。
3. 矿场算力币：按固定 10000:1 折算，经 `MiningFarmService.deduct_compute_coins(amount, reason)` 系统级接口执行，不收提现手续费。
4. 股市证券币：按 1:1 整数折算，经 `StockMarketService.deduct_securities(amount, reason)` 执行并写入 `bank_deduct` 类型交易记录。

四层抵扣后仍有剩余债务则核销并触发信用违约：写入冻结时长、广播 `loan_auto_settled(message, defaulted=true)`，横幅显示“【信用违约】”前缀；正常扣清显示“【银行通知】”。两个 `deduct_*` 接口只允许银行级联等系统流程调用，普通兑换仍走各自服务的充值与提现入口。

## 5. 持久化

- 独立写入 `user://bank_state.json`，版本 1；金额全部为整数星穹，计时字段只保存剩余在线秒数。
- 存取款、签订、放款、兑付走 `_flush_linked_saves()` 与星穹存档同路径落盘；计息与倒计时按 0.5 秒合并写盘。
- 战斗期间存档挂起，战斗结束、窗口关闭或服务退出时统一补写；战斗中到期的兑付与扣款只做内存结算。
- 读档时存单数据异常退还本金、贷款数据异常直接核销，不执行补扣。
- 文件已加入存档白名单，随导出、导入与删除统一处理。

## 6. 扩展注意

- 银行读取大盘只用 `get_market_snapshot().market_state`（长期大盘），不受事件临时大盘影响。
- 活期利息按结算瞬间余额计算，周期内的余额变动不做加权；调整口径时同步机制总表。
- 新增抵扣资产层时保持“整数星穹口径 + 服务公开系统级接口 + 顺序写入文档”三个约束。
