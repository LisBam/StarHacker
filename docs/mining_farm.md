# 量子算力矿场

本文档说明量子算力矿场的服务边界、在线结算与离线收益、资产与固件升级、算力合同、增益联动、UI 和持久化。兑换比例、资产价格、产出、固件费用、合同费率、解锁门槛、增益数值与持续时间统一维护在 `docs/游戏机制与玩法内容.md` 第 17、19 章。

## 1. 模块边界

| 实现 | 职责 |
| --- | --- |
| `res://scripts/game/mining_farm_service.gd` | 算力币、资产数量、固件等级、永久解锁、在线累计、离线补发、收益、增益、超频、算力合同与存档的唯一所有者 |
| `res://scripts/ui/mining_farm_panel.gd` | 展示快照、输入数量、播放余额和卡片动效、发起服务命令 |
| `res://scripts/components/mining_income_float_emitter.gd` | 显示真实收益结算产生的飘字，不修改余额 |
| `res://scripts/ui/main_menu.gd` | 创建矿场遮罩并控制面板打开或关闭 |

面板关闭后只停止 UI `_process()`、进度和动画；常驻服务继续按后台周期结算。面板不缓存真实资产所有权，也不直接访问库存或股市内部字段。

## 2. 在线结算与离线收益

- 服务使用跨场景常驻处理模式，主菜单、局外面板、战斗和暂停都计入在线时间。
- 每次落盘同时写入最后在线时间戳；该时间戳只用于下次启动补发离线收益，不参与任何在线计时。
- 下次启动加载存档后按 `floor(基础总产出 × 有效离线秒数 × 25%)` 一次性补发离线收益；有效离线秒数按 8 小时封顶，基础总产出包含固件加成、不包含任何临时增益。
- 系统时钟被回拨导致离线秒数为负、或补发结果为 0 时直接放弃本次补发，不产生报告。
- 补发结果记录为一次性离线收益报告，矿场面板启动后首次打开时弹出并消费；骇入增益、超频与合同的剩余时长在离线期间均不消耗。
- 面板打开和关闭使用不同结算频率，但都只消费累计时间中的完整秒数；小数余量保留到下一次结算。
- 单次收益由基础总产出和当前有效增益计算，服务统一向下取整后增加整数算力币。
- 打开面板前先结算后台累计时间，随后由 UI 从上次显示余额过渡到服务真实余额。
- 收益飘字只响应实际产出结算；充值、提现和资产出售不伪装成挂机收益。
- 单个资产卡片的视觉发射按“每台资产每秒一次”累计，每个逻辑次数始终生成一个只显示单台收益的独立飘字。单帧最多创建 12 个标签，单卡每秒最多发射 8 个飘字（持有量超过该速率时超出的视觉次数直接丢弃），积压队列上限为单帧上限的 2 倍，防止大持仓下标签无限堆积；飘字始终不修改真实余额。

结算周期、取整方式和公式数值见机制总表。

## 3. 资产、固件升级与解锁

- 资产定义集中在 `MiningFarmService.ASSET_DEFINITIONS`，每项包含稳定 ID、名称、购买价、单台产出、解锁门槛和说明。
- 持有数量是非负整数。购买成功后立即开始参与下一结算周期，出售成功后立即降低基础产出。
- 每类资产拥有独立的固件等级（0 至 5 级），单类产出为 `floor(单台基础产出 × 持有数量 × (1 + 10% × 固件等级))`，按类别整体取整保证低产出资产也能获得升级收益。
- 固件升级费用为 `官方购买价 × 等级倍率`，倍率依次为 2、6、18、54、162（对应 0→1 至 4→5 级）；升级要求当前持有该资产至少 1 台。
- 固件等级永久生效，出售资产不返还升级费用、不回退等级；固件加成计入基础总产出，因此参与解锁门槛判定。
- 解锁条件只读取不含临时增益的基础总产出（含固件加成）。
- 解锁结果永久保存；达到门槛后，即使出售资产导致基础产出下降，也不会重新锁定。
- 出售价格按当前资产定义计算，不维护历史买入批次或成本。

新增资产必须只在服务定义表中建立一次，并由面板按服务顺序动态展示；不得为单个资产创建专用按钮分支。

## 4. 货币交换

```text
数量弹窗输入整数
    -> 确认弹窗展示兑换结果
    -> MiningFarmService 复核余额与参数
    -> GlobalInventory 原子扣除或增加星穹
    -> 服务增加或扣除算力币
    -> 两个资产服务立即保存
```

- 充值参数表示要扣除的星穹，服务先调用 `GlobalInventory.spend_coins()`，成功后再增加算力币。
- 提现参数表示希望到账的星穹，服务根据兑换损耗反算所需算力币，余额足够后完成两边变更。
- UI 预览不构成最终结果；确认时必须重新校验余额、数量和兑换规则。
- 普通收益与单服务资产交易可合并写入；充值和提现属于跨文件资产变更，必须立即保存。
- 正式战斗运行期间矿场写盘完全挂起：后台产出仍按周期在内存结算，磁盘写入只置挂起标志；战斗结算、窗口关闭请求与节点退出场景树时统一落盘一次，保证战斗帧不受磁盘 IO 影响且余额零丢失。

## 5. 算力合同

- 合同定义集中在 `MiningFarmService.CONTRACT_DEFINITIONS`，每项包含稳定 ID、名称、在线时长、兑付比例和说明；当前为短期（30 分钟、92%）、标准（2 小时、95%）、长期（6 小时、98%）三档。
- 签订时玩家选择到期到账的整数星穹，立即锁定 `ceil(到账星穹 × 10000 ÷ 兑付比例)` 算力币；锁定资金离开余额，不参与后续交易校验。
- 同一时间最多存在一份进行中合同；合同中途不可撤销，剩余时长只消耗在线时间。
- 倒计时归零后自动完成：约定星穹直接进入局外库存，无需玩家确认或领取。局外完成时矿场与星穹存档立即同步保存；战斗期间完成只做内存结算并挂起写盘，沿用战斗写盘挂起规则。
- 合同的定位是“锁仓换更优费率”：三档费率均优于 10% 的即时提现手续费，与灵活提现形成资金调度决策。
- 加载存档时若合同类型已被移除或计时数据损坏，锁定算力币原额退回余额且不发放星穹。

## 6. 临时增益与联动

### 成功撤离增益

正式骇入成功撤离后，`CombatHud` 把结算前随身物品的实际总价值传给 `apply_successful_extraction_buff()`。训练场、死亡和主动逃跑不调用该接口。多次成功撤离的比例与在线剩余时间按机制规则叠加。

### 股市联动

`StockMarketService` 在行情完成后发送 `market_refreshed(refresh_source)`。矿场只响应 `settlement` 正式刷新，并读取稳定股票 ID `hacker_tech` 的本轮涨跌；面板微行情和局外小幅刷新不改变矿场联动状态。

### 超频

玩家在面板主动触发的免费增益：产出加算 +50%（单独生效时 ×1.5），持续 300 秒在线时间，结束后进入 1800 秒在线散热冷却，散热期间不可再次启动。启动要求基础总产出大于 0；超频与散热的剩余时长写入存档且离线不消耗。

全部增益在服务内加算后统一作用于基础总产出。UI 只显示服务给出的有效比例和剩余时间。

## 7. UI 约定

- 顶部显示动画余额、星穹折合值、当前每秒产出和增益状态；进度条只表达产出节律，不驱动真实结算。
- 产出状态区下方提供超频按钮，三态文案分别为“超频 ×1.5（300秒）”、“超频中 MM:SS”（禁用）和“散热中 MM:SS”（禁用）；倒计时由面板按 0.25 秒轮询快照刷新，文本未变化时不写入控件。
- 标签页固定为“可购买资产、已持有资产、算力合同”三页。可购买与已持有页使用同一资产顺序。已持有页可保留数量为零的资产占位，但只有真实持有的资产显示运行状态、收益反馈、固件升级和出售入口。
- 已持有页在持有数量大于 0 时显示当前固件等级与固件加成后的本类实际产出，并提供“固件 Lv.N→N+1”升级按钮；满级后按钮文案为“固件已满级”并禁用。固件升级跳过数量弹窗，直接进入二次确认。
- 算力合同页首位展示进行中合同卡片（锁定金额、到期到账星穹、剩余在线倒计时、不可撤销说明），随后按定义顺序展示全部合同类型；存在进行中合同时签订按钮统一禁用为“已有进行中合同”。
- 每个资产飘字固定显示单台每秒收益，字号为 12；固件升级后飘字数值为单台加成收益向下取整，仅影响视觉，真实结算仍按类别整体取整。持有量只提高独立飘字出现频率，不产生合并大飘字。所有资产飘字持续 0.85 秒、上浮 24 像素，横向随机范围为正负 14 像素；单帧创建保护上限为 12。
- 资产解锁门槛只在购买页解释，避免两个页签重复维护同一规则。
- 购买、出售、充值、提现和合同签订复用 `SellQuantityDialog` 输入整数，随后复用 `CommonConfirmationDialog` 二次确认；固件升级和超频只使用二次确认。
- 启动补发的离线收益报告在面板首次打开时使用通用信息弹窗展示离线时长、折算规则与到账金额，只弹一次。
- 交易失败和规则提示使用通用信息弹窗，不直接创建原生 `AcceptDialog`。
- 矿场遵守全局窗口主题；颜色、边框、控件与动效尺寸见 `docs/ui_style.md`。

## 8. 持久化

`user://mining_farm_state.json` 由 `MiningFarmService` 独占，保存：

- 存档版本。
- 算力币余额。
- 各稳定资产 ID 的持有数量。
- 各稳定资产 ID 的固件等级。
- 永久解锁表。
- 成功撤离增益比例与剩余在线时间。
- 股市联动状态。
- 超频剩余在线时间与散热剩余在线时间。
- 进行中合同的稳定 ID、剩余在线时间、到期到账星穹与锁定算力币。
- 最后在线时间戳（仅用于下次启动补发离线收益）。

资产与合同定义本身不写入存档。新增资产缺失记录时按零持有、零固件等级处理；正式版本发布前删除或改名稳定 ID 不提供旧存档迁移，现有测试存档中的对应资产可以失效，进行中合同的类型失效时锁定算力币退回余额。普通结算与资产交易使用合并保存，跨星穹兑换与合同到期交付立即保存矿场和全局库存（战斗期间挂起）。

## 9. 扩展约定

- 新收益来源通过服务方法或明确信号接入，不允许 UI 直接修改余额。
- 新增增益时明确其叠加方式、持续时间单位、暂停行为、存档字段和离线规则，并同步机制总表。
- 新增外部联动时使用稳定来源 ID 和枚举式刷新来源，避免依赖显示名称或模糊布尔值。
- 新增资产字段时为当前结构提供明确默认值，并同步资产卡片展示与验证用例；正式版本发布前不维护历史结构升级。
