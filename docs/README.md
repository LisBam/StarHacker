# 项目文档导航

本目录是项目机制、架构和敌人 AI 的长期维护入口。文档描述应与当前脚本、场景和资源默认值保持一致；涉及玩法或数值的改动必须同步更新《游戏机制与玩法内容》。

## 阅读顺序

1. `游戏机制与玩法内容.md`：游戏设计与默认数值的唯一权威快照，适合确认玩家实际体验、概率、时间、费用和损失规则。
2. `game_framework.md`：场景入口、模块职责、数据流、可调参数和扩展约定，适合定位实现文件与系统边界。
3. `ui_style.md`：全项目窗口主题、颜色、控件状态和接入边界，适合新增或维护任何菜单、面板与弹窗。
4. `enemy_ai.md`：敌人人口加载、感知、记忆、搜查、寻路和远程攻击规则，适合维护 AI 与性能逻辑。
5. `stock_market.md`：股市行情、交易、持仓、事件、行为采集和存档边界，适合维护局外永久资产玩法。
6. `mining_farm.md`：矿场资产、在线产出、增益、交易和 UI 维护约定，适合维护量子算力矿场。

## 维护边界

- 玩法规则、概率、时间、距离、伤害、费用、数量上限等数值，以 `游戏机制与玩法内容.md` 为统一说明入口。
- 组件职责、场景关系、存档服务、UI 数据流和扩展方式，以 `game_framework.md` 为准。
- 窗口颜色、边框、按钮状态、输入控件和主题接入方式，以 `ui_style.md` 为准。
- 敌人 AI 的状态流转、记忆层级、虚拟人口和导航约束，以 `enemy_ai.md` 为准。
- 股市服务、交易数据流、行为采集接口与版本 9 持仓结构，以 `stock_market.md` 为准。
- 文档与实现不一致时，应先以当前运行代码、场景覆盖值和 `.tres` 资源为事实来源，再同步修正文档；不得只修改文档掩盖实现差异。

## 主要实现目录

- `res://scripts/components/`：单一职责战斗、移动、感知、库存与伤害组件。
- `res://scripts/data/` 与 `res://data/`：武器、强化石、修复包的数据结构、品质规则和资源默认值。
- `res://scripts/game/`：战斗世界、库存、商店、锻造、会话和输入等全局服务。
- `res://scripts/ui/`：仓库、商店、锻造、战斗 HUD、地图、结算和物资撤离 UI。
- `res://scenes/`：角色、敌人、环境、弹体、掉落物和界面场景组合。
